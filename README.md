# 🤖 Chat Bot Personalized

Este es un bot básico hecho en Python que responde a diferentes preguntas y mensajes que escriba el usuario.

El bot todavía es sencillo, ya que las preguntas y respuestas están escritas directamente dentro del código. La idea es irlo mejorando poco a poco hasta convertirlo en un bot más completo.

Primero necesitas tener instalado **Python 3** en tu computadora.
